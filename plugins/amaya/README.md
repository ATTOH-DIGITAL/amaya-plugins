# amaya — UK business formation, in Claude Code

Practical, accurate guidance for setting up and running a UK business — from **AMAYA Holdings**.

## What's inside

| Skill | What it does |
|-------|--------------|
| `uk-company-formation` | Choose a structure (sole trader / Ltd / LLP), incorporate correctly (name, registered office, share structure, PSC, SIC, IN01), and work the post-formation compliance calendar (Corporation Tax, VAT, PAYE, Confirmation Statement, accounts). |

More SME-operations skills are on the way.

## Install

```
/plugin marketplace add ATTOH-DIGITAL/amaya-plugins
/plugin install amaya@amaya
```

Then ask things like *"how do I set up a UK limited company?"* or `/amaya:uk-company-formation` — the skill is also model-invoked when the topic comes up.

## Notes

- **Information only** — not legal, tax, or accounting advice. Verify current fees and thresholds on GOV.UK.
- No telemetry, no network calls, no credentials — these are plain Markdown skills.
